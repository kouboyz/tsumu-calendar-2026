中学生の女の子がスマホで使う「夏休みの目標管理＆カレンダーアプリ」のモバイルUIを作成してください。
事前の計画立案と、毎日の記録の「シンプルさ」を両立させたデザインにします。

【技術スタック・アーキテクチャの指定】
GitHub Pagesで静的ホスティング（SPA）を行うため、以下のフロントエンド技術でコードを生成してください。
・フレームワーク: React (Vite)
・言語: TypeScript
・スタイリング: Tailwind CSS
・状態管理: カスタムフック + localStorage（バックエンド不要でブラウザ完結）
・UI操作: dnd-kit等のモダンなライブラリを用いたドラッグ＆ドロップの実装
・アイコン: Lucide React等
※AIエディタでの継続的な開発（バイブコーディング）を前提とし、コンポーネントが適切に分割された保守性の高いコードを出力してください。

【デザインのテイスト】
・LDHのガールズグループ「Girls2」のような、ポップでエネルギッシュ、かつスタイリッシュなテイスト。推しは鶴屋美咲。
・毎日開くのがワクワクする推し活グッズのような画面にしてください。

【画面構成とUI機能】
以下のエリアを縦に配置した1画面（SPA風）で構成してください。

1. ヘッダーエリア（モチベーション）
・「夏休み 残り〇日！」のポップなカウントダウン。
・全体の達成度がわかるキラキラしたプログレスバー。

2. プールエリア（計画・イベントカード置き場）
あらかじめ用意されたタスクやイベントが、トレカや付箋のような可愛いカードとして並んでいるエリア。（横スクロールまたはタブ切り替えで一覧できるUI）
以下の分類でカードを用意してください。

・夏休みの宿題（教科）:
共通、国語、数学、社会、理科、英語、音楽、美術、技術、家庭、保体のカード。
※宿題は量が多いことを考慮し、1つの教科カードから「数学①」「数学②」のようにタスクを複数に分割して、カレンダーの別々の日に何個でも登録（配置）できる仕様・UIにしてください。

・イベント登録:
「友人とのお出かけ」「お祭り」「旅行」などの特別な日の予定カード。宿題とは違う、特別感のあるポップなデザイン（柄入りや少しリッチな装飾など）にしてください。

・カードはカテゴリごとに色分けされており、ドラッグ＆ドロップで動かせるような見た目（つまみアイコンなど）にしてください。

3. カレンダーエリア（予定の組み込みと実行）
・1ヶ月（または直近1週間）のカレンダー表示。
・ユーザーは上の「プールエリア」から、このカレンダーの日付枠にカードをドラッグ＆ドロップして「計画」をはめ込める想定のUI。
・カレンダー上の日付同士でも、カードを移動して予定を「組み替え」できるように見せてください。

4. 毎日のアクション（超シンプル入力）
・今日の日付に入っている計画カードを「ワンタップ」するだけで、完了の「🌟（星マーク）」のスタンプが押され、カードが明るく光る（または少しグレーアウトして完了状態になる）デザインにしてください。
・文字入力は一切不要で、チェックをつけるだけの仕様です。
